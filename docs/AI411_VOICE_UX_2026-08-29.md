## 1. Tension

Callers already go off-script (“what’s a good date tonight”, movies, the Hipp). The current prompt treats that as an **events-discovery ceremony** (interest/QOTD → category counts → 2–3 titles → FOMO opt-in). That tree dies when the job is a **direct request**.

v1 still must **not** book seats, make reservations, or claim a concierge. The useful move is: short grounded answer **or** spoken venue number + log. SMS of official links only after the caller asks (A2P still gated on FMWS formation).

## 2. Current stack (facts, 2026-08-29)

### Voice path (prod)

`realtime.py` bridges Twilio Media Streams ↔ `wss://api.x.ai/v1/realtime?model=grok-voice-latest`. Both sides **G.711 μ-law 8 kHz** (`audio/pcmu`); payloads pass through. Barge-in: `input_audio_buffer.speech_started` → Twilio `clear`. VAD: `GROK_VAD_SILENCE_MS=600`. Greeting is **pinned** to `AI411_GREETING = "A411 here."` via `opening_response_create`. Sesame / DeepInfra **unused** in this backend.

Local `voice-agent/.env`: `VOICE_BACKEND=grok-realtime`, `GROK_VOICE=eve`, `XAI_VOICE_AGENT_ID` empty. Leave it empty — console agents greet in PCM16 and Twilio plays that as μ-law static.

`call-log.db` has **0 transcript turns**. There is no stored TTFA today.

### Pipeline / Sesame path (not prod)

`tts.py` → DeepInfra `sesame/csm-1b`, whole WAV, cache by hash. README: warm 2–4 s per utterance; cold reload 60–90 s. Twilio `<Play>` + nested `<Gather>` barge-in only.

### Prompt tree (`voice-agent/ai411.py`)

`CONVERSATION FLOW` + `EVENT DISCOVERY` **forbid** `search_events` until an interest, QOTD answer, or “anything”. `OPENERS` still include filler: “Sure thing.” / “Absolutely.” / “Good question.” / “Happy to help.” / “One moment.” Pipeline mode prepends those; realtime `openers=False` but the list still contaminates tests and any pipeline fallback.

No `transfer` / `<Dial>` tool exists. Tools end at `send_sms_links` + `end_call`.

### Events store

`mcp-server/events.py`: `community` + `visitgainesville` only. Empty store is valid. `when=` ∈ `{tonight, tomorrow, this_weekend, ""}` — **exact dates fail**.

This checkout `data/events.json`: **6 community rows** (Acoustic Open Mic / Park Jam / House Show, some July 2026, duplicated). **0** `visitgainesville` rows. Do not treat as prod PVC.

## 3. Intent taxonomy (replace the rigid tree)

One primary intent from the first useful utterance. Explicit request **beats** discovery ceremony.

| Intent | Example | Action | Not allowed |
|--------|---------|--------|-------------|
| `directory` | “hours for the Hipp” | `lookup_business` / knowledge | invent NAP |
| `events_browse` | “what’s going on this weekend” | optional one interest Q **only if** query is empty; else `summarize_event_categories` → `search_events` | dump 12 titles |
| `date_night` | “what’s a good date tonight” | infer `when=tonight`; search arts **and** food in parallel; speak **2** verified options + venue phones | book, itinerary theater, “I reserved” |
| `cinema` | “movies tonight” / “Regal” | if store has `kind=film_showtime` and fresh: 2 titles + times; else honest miss + spoken theater number | scrape-guess showtimes |
| `hippodrome` | “what’s at the Hipp” | `search_events` query/venue Hipp; VG organizer rows first | claim sold-out / ticket hold |
| `connect` | “just call them” | speak E.164 + log `connect_spoken`; no `<Dial>` in v1 | outbound dial from 844 |
| `post` | “post my event” | confirm → `submit_event_broadcast` | unconfirmed posts |
| `memory` | “remember I like jazz” / “forget me” | existing consent tools | FOMO/page without explicit yes |
| `emergency` | fire/police/medical | hang up, call 911 | handle it |
| `off_script` | anything else | one short grounded try **or** connect/log | dead tree, “great question”, recap |

Slots: `intent`, `when` (enum **or** ISO `start_at`/`end_at` ET), `place`, `category`, `free_only`. Ambiguous “Friday” → say the resolved date once.

### Route: “what’s a good date tonight”

1. Intent `date_night`, `when=tonight`. **Do not** ask “what do you like?” first.
2. Tools: `search_events(when=tonight, category=arts|music)` + `search_events(when=tonight, category=food)` (or one query + two category calls). Limit 2 spoken.
3. Speak: two names, one detail each, venue phone if known. “I can’t book. I can text the official page, or I can give you their number.”
4. Log `intent=date_night` on the call row (`t-ai411-connect-not-book`).
5. If store empty/stale: say so in one sentence; offer Hipp / a known restaurant number from `lookup_business` — never invent a show.

## 4. How to speak

- First audio on answer: exactly `A411 here.` then wait (already pinned in realtime).
- After that: **answer first**. 1–3 short sentences. One question max.
- Ban list (strip from `OPENERS` and prompt): “great question”, “good question”, “sure thing”, “absolutely”, “happy to help”, “of course”, “one moment”, “let me check”, recap-the-menu.
- Keep: “A411 here.” / “Got it.” / “Thanks.” / “No problem.”
- URLs: never speak them. `send_sms_links` only if they ask (A2P/formation still a wall).
- Stale/missing: say stale/missing. Do not fill with charm.

## 5. Latency budget

User-perceived metric: **TTFA** = `speech_stopped` / `input_audio_buffer.committed` → first `response.output_audio.delta` **and** first Twilio `media` send.

| Segment | grok-realtime (keep) | Sesame pipeline (do not flip prod) |
|---------|----------------------|-------------------------------------|
| VAD silence | 600 ms now; try 400 after barge-in tests | Twilio Gather timeout |
| First model audio | vendor: sub-second; **unmeasured here** | n/a (LLM then TTS) |
| TTS first byte | included in S2S | **measured below** |
| **Budget** | **p50 ≤ 800 ms · p90 ≤ 1.2 s · p95 ≤ 1.8 s** | fails budget |

Instrument `realtime.py` (monotonic clocks, no raw audio in logs). 30 probe turns before claiming a win. Empty `transcript_turns` means we cannot cite prod TTFA today — do not invent it.

Barge-in already exists; do not add spoken “go ahead” after interrupt.

## 6. Sesame CSM spike (measured)

**Question:** can Sesame CSM replace `GROK_VOICE=eve` on Twilio μ-law without breaking barge-in?

### Measured (this host, DeepInfra `sesame/csm-1b`, 2026-08-29, not Vina)

| Probe | Result |
|-------|--------|
| REST “A411 here.” | HTTP 5.879 s wall · `runtime_ms=3837` · **WAV 24 kHz 16-bit mono** · 2.07 s audio · cost $0.00007 |
| REST longer line | HTTP 9.196 s wall · `runtime_ms=4331` · same WAV format |
| `stream=true` | SSE · TTFB **1.89 s** · total 3.42 s · magic `RIFF…WAVE` (still 24 kHz WAV, **not** μ-law) |

Twilio Media Streams need **raw PCMU 8 kHz**, no WAV header. Sesame output requires resample 24k→8k + μ-law encode **and** a streaming TTS loop that grok-realtime does not have. Hybrid (Grok S2S + swap audio for Sesame) means suppressing Grok audio, adding 2–4 s, and killing native barge-in.

### Comparison

| | grok-realtime + eve | DeepInfra CSM | Vogent CSM | xAI custom voice cloned from CSM sample |
|--|---------------------|---------------|------------|-----------------------------------------|
| μ-law 8 kHz | native | no (WAV 24k) | vendor 200–400 ms TTS; telephony unproven here | native if used on `/realtime` |
| Barge-in | yes | no | platform | yes |
| Sesame **inference** | no | yes | yes (re-arch CSM) | **no** (timbre only) |
| Prod | **keep** | invalidate | invite API; extra vendor ≤ $200/mo band | spike #2 |
| `XAI_VOICE_AGENT_ID` | unset | n/a | n/a | still unset |

**Verdict: PARTIAL / do not flip prod.**

- Replacing `grok-realtime` with pipeline Sesame **fails** the latency budget and μ-law constraint.
- DeepInfra `stream=true` is still WAV, TTFB ~1.9 s — too slow and wrong codec.
- Self-host streaming CSM (`ulaw_8000`) needs a GPU — **out of scope** (Vina dock reserved).
- If the product need is “not eve” **sound**: clone `conversational_a` into an xAI custom `voice_id`, keep grok-realtime, still no console `agent_id`. That is timbre, not CSM.
- If the product need is **actual CSM**: Vogent (ask, do not buy) or a later isolated `VOICE_BACKEND=sesame-stream-spike` behind tests. Not a prod image.

Spike leftover (throwaway, not this ship): `voice-agent/spikes/001-sesame-mulaw/` — 24k WAV→8k PCMU roundtrip + TTFB log. Do not wire into `server.py`.
