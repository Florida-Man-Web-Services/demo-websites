# AI 411 — twelve one-job angles (v3)

Why the old pack felt confusing: every ad tried to be events + memory +
people-matching + free website + “A411 here.” That is four products. A
cold viewer cannot tell what to do.

Rule for this slate: **one job per ad.** If a line is not that job, cut it.
Never put the shop offer in a night-out ad. Never put QOTD in a shop ad.

Two offers only (pick one per ad):

- Locals: Call AI 411. Get a plan for Gainesville tonight.
- Shops: Request a callback. Free demo website interview.

Landing: https://ai411.floridamanweb.online/ai411/
Compliance: inbound + web form. No cold outbound claims. No fake stats.

Awareness (Schwartz): most Meta/TikTok viewers are unaware or
problem-aware. Do not lead with “voice AI / category counts / QOTD”
unless the angle is marked solution-aware.

## What we retired from v2 (on purpose)

- Stacking events + memory + QOTD + free site in one caption
- “Yellow Pages energy, transformer brains” (clever, unclear)
- “A411 here” as the whole ad (brand mnemonic, zero job)
- Consent-memory lecture on cold traffic (solution-aware at best)
- Fake specificity (no invented call counts)

Memory (“it remembers if you ask”) is a retarget / second-touch line,
not a cold angle. Use it on visitors who already called or hit the lander.
